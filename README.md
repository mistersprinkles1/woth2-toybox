# WOTH2 Toybox (web)

A map companion for Way of the Hunter 2: every herd and need zone, camps, hunting stands, habitat jobs, regions, your own pins and herd notes, and the encyclopedia. Runs in the browser, no save needed (PC, PlayStation and Xbox players).

Open it: https://mistersprinkles1.github.io/woth2-toybox/
